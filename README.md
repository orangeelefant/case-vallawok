# Case study — Vallawok

Samma case finns i samlingen [case-studies/vallawok](https://github.com/orangeelefant/case-studies/tree/main/vallawok).

How [Vallawok](https://vallawok.se) worked online in the version [Webraketen](https://webraketen.se) built, which is the version this case describes. The site now live at vallawok.se is run by Vallawok on WordPress, a platform Webraketen does not run.

## Om Vallawok

Vallawok är en omtyckt thairestaurang i Linköping sedan 2012, belägen på Wernersgatan 1. Vi lagar äkta thaimat med färska grönsaker — wok, curry, nudlar och klassiker från Thailand. Ät på plats, hämta eller få hemlevererat via Wolt och Foodora. 4,2 av 5 på Google och superrestaurang-betyg hos Foodora.

→ [vallawok.se](https://vallawok.se)
